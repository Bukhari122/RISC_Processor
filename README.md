# MIPS CPU Design

A cumulative final project completed for **COE 608: Computer Organization and Architecture** at Toronto Metropolitan University.

For this project, I designed and implemented a **RISC/MIPS-based CPU using VHDL** and synthesized it using **Quartus-II** for an FPGA development system. The project involved designing the CPU's main components and connecting them together to create a functional processor.

### What I Learned

This project gave me hands-on experience with **CPU architecture, digital logic, VHDL, FPGA development, and hardware design**. It also helped me understand how components such as the datapath, control unit, registers, and ALU work together to execute instructions.
